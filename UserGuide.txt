RemoteHub 1.4.2  使用说明
============================================================

一、软件用途
  多标签的远程桌面工作台。远程画面由 Windows 自带的 RDP ActiveX 控件
  (mstscax.dll) 直接嵌入本程序窗口，不是启动 mstsc.exe 外部窗口。
  可同时连接多台主机；被控端只需开启系统「远程桌面」，无需安装任何 agent。

二、界面
  · 标题栏：程序名，右侧为「深色 / 浅色」主题、快捷键说明与窗口按钮。
  · 菜单栏：文件 ｜ 编辑 ｜ 视图 ｜ 工具 ｜ 帮助。全部命令都能从这里找到。
      文件    新建 / 编辑 / 删除连接、批量导入、导出 CSV、退出
      编辑    复制一份、搜索主机、锁定台账、主密码
      视图    跟随窗口、主题、宫格、截图、全屏、关闭标签
      工具    局域网扫描、重新探测、文件共享、安全键、批量连接、保存到台账
      帮助    连接历史、环境自检、快捷键说明、关于
  · 工具栏：纯图标（鼠标悬停显示名称），分组如下
      新建 ｜ 编辑 ｜ 删除 ‖ 连接 ｜ 断开 ｜ 重连 ‖ 全屏 ｜ 文件共享 ｜ 截图 ｜ 宫格
      右端为「快速连接」输入框（输 IP 回车即连）与「⋯」最近连接。
  · 左侧「主机台账」：按分组列出主机，名称下方显示地址；主机项相对分组
    缩进一级，并用一条细导轨连回分组，能直观看出属于哪一组；
    顶部搜索框可按名称 / IP / 用户名 / 备注过滤；底部为统计与「新建主机」。
    默认宽度约 208 像素，可拖动中间的细分隔条自由调整。
  · 右侧工作区：每个会话一个标签页，标签上的圆点表示状态
    （绿色=在线，蓝色=当前标签，灰色=未连接）；点标签右侧 × 可关闭，
    标签条右侧的「＋」可直接新建会话；标签宽度按最长的主机名自适应。
    没有打开的会话时，工作区保持空白，只在中间显示一行操作提示。
  · 主题：顶栏右侧的月亮 / 太阳图标切换深色 / 浅色，选择会被记住，
    保存在配置文件旁的 ui.ini 中（只记录主题与「跟随窗口」两项）。

二之二之二之二、1.4.2 界面细节

  这一版不新增功能，只把程序自绘的控件与 Windows 原生控件的混排清理干净，
  同一个对话框里不再出现两套视觉语言。

  · 数字输入框（端口 / 宽高 / 超时 / 空闲锁定）改为自绘：圆角输入框 +
    右侧上下双箭头，不再是系统方角灰色步进器。
  · 复选框（显示密码 / 智能缩放 / 兼容模式 / 磁盘映射 / 剪贴板共享）改为
    自绘：14 像素圆角方框，勾选时以主题强调色填充配白色对勾。
  · 局域网扫描的结果列表改为自绘：自定义列标题条、圆角复选框、随主题
    着色的状态文字与行分隔线，不再是系统灰底表头 + 方角勾选框。
  · 图标笔宽按屏幕像素定义，缩小时不再发虚；月牙与问号图标重画。
  · 标题栏、菜单栏、工具栏、侧栏、状态栏的间距与对齐逐项校正。

二之二之一、1.4.1 修复

  1) 拖动窗口大小时，右上角的关闭 / 最小化 / 最大化按钮不再错位
     这三个按钮是程序自己画、自己定位的。原先窗口宽度变化时没有重新
     贴边，导致窗口拉宽后按钮停在旧位置、不再位于右上角；窗口拉窄后
     按钮超出标题栏右边界被裁掉，看起来像被遮住。
     现在窗口每变一次宽度，标题栏都会重新排布，三个按钮始终紧贴右缘。

二之二、1.4.0 界面重做

  界面按传统 Windows 桌面工具重排，去掉了原先那种「产品落地页」式的排版：

  · 删除居中的欢迎页（图标 + 大标题 + 说明 + 圆角按钮 + 最近连接卡片）。
    没有会话时工作区就是空的，只留一行提示。
  · 恢复真正的菜单栏：文件 / 编辑 / 视图 / 工具 / 帮助，所有命令都能点到。
  · 工具栏改为纯图标 + 悬停提示，按功能分组，不再是一排带文字的胶囊按钮。
  · 圆角统一收紧到 3 像素，窗口改为直角，阴影与装饰性图标全部去掉。
  · 最近连接移到工具栏「⋯」下拉，点一下直接重连。
  · 对话框去掉分组块上的装饰图标与彩色竖条，标题副标题改为一行事实说明。
  · 界面文案整体重写：去掉教程式编号、括号注释和「推荐」这类推销词。

二之二之二、1.3.0 新增功能

  0) 1.4.0 修复：点击全屏出现大黑边
     进入全屏（F11 / 工具栏「全屏」/ 标签右键）时，远程桌面分辨率会同步
     调整为整块屏幕大小；退出全屏后自动恢复为会话区域大小。
     用 Ctrl+Alt+Break 自行退出全屏，程序也会检测到并同步恢复分辨率。
     若远程系统不支持动态改分辨率，则退回拉伸显示，避免四周出现黑边。

  1) 快速连接栏
     命令栏右侧的「快速连接：IP / 名称」输入框，输入后回车即连：
       · 名称 / IP / 备注能在台账里找到 → 直接用该主机的配置连接；
       · 找不到 → 以临时连接打开（不写台账），之后可用
         「⋯ → 将当前会话保存到台账」再入库。
     支持 host:端口 与 用户@host 两种写法。Ctrl+Q 可聚焦到该输入框。

  2) 主机在线探测
     启动时及每 30 秒自动探测台账里的主机，左侧状态点：
       绿色 = RDP 端口可连接（真正在线）
       黄色 = ping 通，但 3389 端口无响应（未开远程桌面 / 防火墙拦截）
       灰色 = 离线，或尚未探测
     手动重探：「⋯ → 立即重新探测在线状态」。探测在后台线程进行，
     不卡界面；状态栏「可达 N/M」为端口可达的主机数。

  3) 局域网扫描
     入口：「⋯ → 局域网扫描 / 发现主机…」。
     「IP 段」支持 192.168.1.1-254、192.168.1.0/24 或单个 IP，
     设定端口与超时后点「开始扫描」，程序并发探测、只列出端口开放的主机。
     勾选后点「加入台账」写入台账，分组为「扫描发现」；重复主机自动跳过；
     「停止扫描」可随时中断。

  4) 一键会话截图
     Ctrl+Shift+S，或「⋯ → 一键会话截图」、会话标签右键「会话截图」。
     截取当前会话画面保存为 PNG，同时放入剪贴板。
     文件位置：安装版 %APPDATA%\RemoteHub\Screenshots，绿色版 Data\Screenshots。
     截取的是屏幕上可见区域，截图前请勿让其他窗口遮住会话画面。

  5) 多画面宫格
     Ctrl+Shift+G，或「⋯ → 多画面宫格」。
     把前 2–4 个会话铺成 2 列（2 台为 1×2，3–4 台为 2×2），每格顶部
     显示编号、主机名与地址；双击标题回到标签视图并选中该会话。
     格子里的会话仍是同一个连接，可直接操作。
     注意：同一台 Windows 主机通常只允许一个交互式会话，连它两次时第二个
     会被拒绝，格子里显示「未连接」—— 这不是宫格的问题，连两台不同主机即可。

  6) 台账主密码 / 离开锁定
     入口：「⋯ → 主密码 / 自动锁定…」。
     · 设置主密码（至少 4 位）后，每次启动先显示锁定遮罩，输对密码才能进入；
       只保存加盐 SHA-256 摘要，不存明文。
     · 「空闲锁定」分钟数：无操作超过该时长自动锁定（0 = 关闭）。
     · 手动锁定：Ctrl+Shift+L 或「⋯ → 锁定台账」；锁定期间快捷键全部被拦截。
     · 忘记密码：删除配置目录中的 vault.ini 即可清除主密码（连同空闲设置）。
     说明：这是【界面锁】，防止他人打开本程序查看台账与已保存密码；
     台账里的连接密码仍由 Windows DPAPI 按当前账户加密，机制不变。

三、远程画面的尺寸（跟随窗口）
  · 默认开启「跟随窗口」：远程分辨率 = 会话区实际大小，画面始终铺满，
    不出现左右或上下的灰边。拖窗口边框、最大化、拖动左右分隔条时，
    远程桌面会自动重新排版（RDP 8.1+ 为在线改分辨率，不掉线）。
  · 关掉后显示为「固定分辨率」：按每台主机配置的分辨率显示，
    超出部分会被缩放到窗口中（保持比例，可能出现灰边），
    改动窗口大小后需要重连才会应用新尺寸。
  · 开关位置：顶栏「跟随窗口」按钮，或菜单「视图 → 远程画面跟随窗口大小」。
    开关状态会记住，对所有会话生效。连接较老的被控端（Windows 7 以前）
    若不支持在线改分辨率，会自动退回等比缩放显示，不会断线。

四、远程音频（1.0.4 新增）
  以前内嵌会话没有设置音频重定向方式，远程机的声音既不会传回本机，
  也没有入口可关。1.0.4 起每台主机可单独选择：

    · 在此计算机播放（推荐）：远程声音实时传回本机音箱 / 耳机。
      适合远程看视频、听提示音、语音会议。
    · 在远程计算机播放：声音留在被控端，本机保持安静。
    · 不播放（静音）：完全关闭音频通道，弱网时最省带宽。

  设置位置：「新建 / 编辑连接 → 高级设置（文件共享 / 音频）→ 远程音频」。
  改动后需要重连当前会话才生效。

  说明：音频重定向走 RDP 的 rdpsnd 虚拟通道。若被控端组策略
  「不允许音频重定向 / 不允许音频录制」被启用，声音仍然不会传回，
  这不是程序问题。用「帮助 → 环境自检」看「音频重定向」一行，
  AudioRedirectionMode 显示「可写」才代表本机控件接受该设置。

五、安全键：向远程发送 Ctrl+Alt+Del（1.0.4 新增）
  远程改密码、打开任务管理器、锁屏都需要 Ctrl+Alt+Del，而它属于
  Windows 的安全注意序列 (SAS)，本地键盘直接按只会作用于本机。
  入口：
    · 工具栏「安全键」
    · 菜单「连接 → 发送 Ctrl+Alt+Del（安全键）」
    · 在会话标签上右键 →「发送 Ctrl+Alt+Del（安全键）」
  原理是调用 RDP 控件的 SendCtrlAltDel 接口，由客户端把它送到远程会话。

  如果本机控件版本没有通过脚本接口暴露该方法，程序会明确提示，
  此时请在远程桌面窗口内按 Ctrl+Alt+End —— 这是 RDP 的标准快捷键，
  效果与远程机的 Ctrl+Alt+Del 完全相同。

六、连接历史（1.0.4 新增）
  每次会话结束后自动记一条：开始时间、主机、账号、在线时长、结果、说明。
  入口：菜单「记录 → 查看连接历史」；菜单里也可以直接清空。
  窗口内提供「导出 CSV」，清空前会二次确认。

  「结果」有四种：
    · 主动断开  — 你点了断开 / 关闭标签 / 退出程序
    · 意外断开  — 网络中断、被控端重启、会话被顶替等
    · 连接失败  — 握手阶段就失败（地址、端口、凭据、策略）
    · 重连      — 点「重连」时结束的上一段会话
  「说明」里的原因码来自 RDP 控件的 ExtendedDisconnectReason。
  只有 0–3 四个常见码有文字描述，其余显示原始数字，不做猜测；
  多数情况下结合被控端事件查看器（TerminalServices 日志）才能定位。

  存储位置：与台账同目录的 history.xml，最多保留 500 条（超出自动
  丢弃最旧的）。历史与台账分开存放，清空历史不影响主机台账。
  隐私提示：历史里会记录主机地址与用户名，但【不记录密码】。绿色版
  把整个目录拷走时历史也会一起带走，介意的话先在窗口里清空。

七、本机与远程之间传文件（1.0.3 新增）
  以前的痛点：内嵌会话默认没有开启「驱动器重定向」，远程机里看不到本机
  磁盘，只能另开一个 mstsc 窗口传文件。1.0.3 起默认打通两条通道，
  并给出一个「传文件」助手，把用法直接摆在界面上。

  开关位置：「新建 / 编辑连接 → 高级设置（文件共享 / 音频）」，
  每台主机独立设置，默认开启；改动后需要重连当前会话才生效。
    · 映射本机磁盘到远程      → RDP 的 RedirectDrives
    · 共享剪贴板（可传文件）  → RDP 的 RedirectClipboard

  入口：工具栏「传文件」、菜单「连接 → 文件共享 / 传输」、Ctrl+T，
        或在会话标签上右键。对话框里提供三种用法：

  方式一：磁盘映射（大文件 / 批量，推荐）
    在远程桌面里打开资源管理器，地址栏输入  \\tsclient\C
    （C 换成本机对应盘符），回车即可看到本机该盘的完整目录树；
    也可以打开「此电脑」，在「重定向的驱动器 / 网络位置」里找到本机磁盘。
    两边都能直接拖、复制、粘贴，双向传输，速度最好。
    对话框里的「复制 \\tsclient 路径」按钮可一键复制该地址。

  方式二：剪贴板快传（几个小文件，或服务端禁用磁盘映射时）
    在「传文件」对话框里点「添加文件 / 添加文件夹」选好本机内容，
    点「放入剪贴板 → 远程 Ctrl+V」，然后切到远程桌面窗口按 Ctrl+V，
    文件就粘贴过去了。原理是 RDP 剪贴板重定向支持 CF_HDROP 文件列表，
    远程端 rdpclip 会在粘贴时把数据通过 RDP 通道取过去。

  方式三：从远程取回文件
    在远程机里复制文件 (Ctrl+C)，切回本机，在「收件目录」里按 Ctrl+V，
    RDP 会自动把文件传回来。点「打开收件目录」会弹出资源管理器，
    直接粘贴即可；目录默认在  用户目录\Downloads\RemoteHub，可以改，
    改完会随台账一起保存。

  会话中新插入的 U 盘：多数系统会在远程端自动出现；若没出现，在远程
  资源管理器按 F5 刷新，或重连一次会话即可。（对应控件开关
  RedirectDynamicDrives 属于非脚本接口，本机自检显示为「不可写」时，
  程序会跳过它，不会误报成「已开启」。）

  如果远程机里看不到本机磁盘：
    · 检查「编辑连接 → 高级设置」里两个开关是否为开，并已重连；
    · 检查被控端组策略：计算机配置 → 管理模板 → Windows 组件 →
      远程桌面服务 → 远程桌面会话主机 → 设备和资源重定向，
      「不允许驱动器重定向」必须为「未配置 / 已禁用」；
    · 检查远程机上的 rdpclip.exe 是否正常运行（可在任务管理器里重启它）；
    · 老系统（Windows 2003 / XP）或某些精简版系统可能不支持文件级
      剪贴板传输，此时改用方式一；
    · 用「帮助 → 环境自检」查看「文件重定向」一行，可确认本机控件是否
      接受这些开关；「磁盘映射 / 剪贴板」显示「开」才真正生效。
    · 若连接时系统弹出资源重定向安全警告，勾选「不再询问」即可，
      该警告由 Windows RDP 客户端控制，不影响嵌套显示。

  安全提示：磁盘映射会把本机磁盘暴露给远程会话，连接不信任的主机时
  建议在「编辑连接」中关掉「映射本机磁盘到远程」，只保留剪贴板。

八、两种版本
  · 安装版：运行 RemoteHub-1.4.2-Setup.exe 安装，提供开始菜单、桌面快捷
    方式（可选）、开机自启（可选）以及「应用和功能」中的卸载入口。
    主机台账保存在 %APPDATA%\RemoteHub\connections.xml，
    连接历史保存在同目录 history.xml。
  · 绿色版：解压后直接运行 RemoteHub.exe，不写注册表、不装服务。
    目录中的 portable.flag 表示绿色模式，台账与历史保存在同目录
    Data\ 下，整个目录可拷到 U 盘带走。
    删除 portable.flag 即切换为安装版的配置位置。

九、快速上手
  1) 双击 RemoteHub.exe；
  2) 点「新建连接」填主机，或点「批量导入」粘贴/选择 CSV 建立台账；
     导入格式支持：host / host:端口 / host,用户 / host,用户,密码 /
     名称,分组,主机,端口,用户,密码,域,备注,共享磁盘,共享剪贴板,音频模式
     （后三列可省略：省略时共享默认开启、音频按「在此计算机播放」；
      音频模式取值 0=本机播放 / 1=远程播放 / 2=静音。导出时始终带这三列，
      密码列始终存在，不导出密码时为空，避免重新导入时列错位）
  3) 双击左侧主机即可连接；每个连接占一个标签页。
  4) 菜单「帮助 → 环境自检」可查看本机 RDP 控件版本、密码注入能力、
     动态分辨率、文件重定向、音频重定向与安全键方法是否可用。

  Ctrl+Q 聚焦快速连接栏            Ctrl+Shift+S  会话截图
  Ctrl+Shift+G 多画面宫格          Ctrl+Shift+L  锁定台账
  Enter  连接选中主机    Delete  删除选中主机
  注意：会话建立后键盘会优先发给远端，此时请用工具栏或右键菜单操作。
  全屏状态可用 Ctrl+Alt+Break 退出；进入 / 退出全屏时分辨率自动同步，
  「跟随窗口」在全屏期间不会把画面压回窗口大小。
  远程机需要 Ctrl+Alt+Del 时，用工具栏「安全键」，或在远程窗口按
  Ctrl+Alt+End。

十一、数据与卸载
  · 密码使用当前 Windows 账户的 DPAPI 加密后落盘，明文只在内存；
    换用户或换机器后已保存的密码将无法解密，需要重新输入。
  · 连接历史不保存密码，只保存主机、账号、时间与结果。
  · 安装版卸载时默认【保留】主机台账与连接历史，以便下次安装继续使用。
    如需彻底清理，手动删除 %APPDATA%\RemoteHub 目录。
  · 绿色版直接删除整个文件夹即可，不会留下注册表项。
  · 「收件目录」只是本机一个普通文件夹，卸载时不会被删除。
